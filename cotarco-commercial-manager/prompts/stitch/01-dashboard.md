# Stitch Prompt — Dashboard

Use o design system aprovado do CCM.

Criar dashboard para dois papéis:

1. Comercial — acompanhamento dos próprios processamentos e ação "Novo processamento".
2. Operador — inclui fila de revisão e alertas gerais.

Elementos:

- greeting;
- KPIs;
- processamentos recentes;
- status badges;
- CTA primário;
- estado vazio;
- loading skeleton.

Prioridade visual: próximos passos operacionais.

Não criar gráficos complexos no MVP.

A UI deve funcionar a 1440px e manter legibilidade a 1024px.
