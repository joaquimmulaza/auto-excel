# Stitch Prompt — Review / Diff

Criar a tela mais importante do produto.

Objetivo: permitir que o Operador e a Comercial compreendam o resultado do processamento antes de qualquer ação crítica.

Header:

- job number;
- profile;
- source;
- date;
- status.

Summary cards:

- total;
- updated;
- new;
- ignored;
- blocked.

DataTable:

- reference;
- old price;
- new price;
- variation;
- old/new stock;
- decision.

Filtros:

- all;
- updates;
- new;
- ignored;
- blocked.

Issue panel:

- code;
- human message;
- row/reference;
- explain with AI.

Footer:

- back;
- reject;
- approve.

Aprovação deve ter aparência deliberada, nunca acidental.
